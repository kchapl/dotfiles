# Dotfiles

Personal dotfiles: shell configuration, git configuration, and an agent skills tree, linked into `$HOME` with GNU Stow.

## Language

**Authored skill**:
A skill written and owned in this repository.
_Avoid_: my skill, custom skill, local skill

**Vendored skill**:
A skill copied into this repository from an upstream source, which owns it.
_Avoid_: third-party skill, external skill, installed skill

**Source**:
The upstream repository a vendored skill came from, named `owner/repo`.
_Avoid_: marketplace, registry, package

**Skill inventory**:
The record of every skill in the tree and where each one came from.
_Avoid_: manifest, catalog
